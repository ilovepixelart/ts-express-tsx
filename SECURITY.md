# Security Policy

This repository is a project template. It is not published as a package and has no
release lines; fixes land on `main`, and projects created from the template pick
them up by updating their own copy.

## Supported Versions

| Version       | Supported          |
| ------------- | ------------------ |
| `main`        | :white_check_mark: |
| anything else | :x:                |

## Reporting a Vulnerability

Please do not open a public issue for security problems. Report them privately
through GitHub's
[private vulnerability reporting](https://github.com/ilovepixelart/ts-express-tsx/security/advisories/new)
form, with the affected commit, a minimal reproduction and the impact you expect.

## Response Timeline

- Acknowledgement within 7 days of the report.
- A fix on `main` targeted within 30 days for confirmed issues, depending on
  severity and complexity.
- Disclosure is coordinated through the GitHub advisory once the fix is on `main`.
